# 💫 About Me:
I am a Computer Science and Engineering student specializing in Cybersecurity, with a strong foundation in core domains such as Data Structures, Operating Systems, Computer Networks, AI/ML and Database Systems. My primary focus is on building practical, real-world security solutions rather than limiting myself to theoretical knowledge.<br><br>I have hands-on experience in Security Operations Center (SOC) environments, where I’ve worked on designing and deploying end-to-end detection and response systems. My work includes integrating tools like SIEM, IDS/IPS, and SOAR to simulate and handle real attack scenarios aligned with frameworks like MITRE ATT&CK.<br><br>I actively build cybersecurity tools and systems, including:<br><br>A Java-based advanced port scanner with features like multithreading, OS detection, banner grabbing, and visualization<br>A Flask-based SIEM system with real-time monitoring and alerting<br>AI-driven Intrusion Detection Systems using reinforcement learning for adaptive threat detection<br>A full SOC lab simulation for healthcare environments with automated incident response workflows<br><br>My current focus is on combining AI with cybersecurity to build intelligent, adaptive defense systems that can detect and respond to threats autonomously, including work on automotive network security and real-time IDS deployment.<br><br>I approach learning by building. Every concept I study is backed by implementation, testing, and improvement. My goal is to engineer security systems that are not just functional, but reliable, scalable, and capable of handling modern attack surfaces.<br><br>I am continuously working towards becoming a Security Architect, with a strong emphasis on detection engineering, threat analysis, and automated defense systems.
